## 2026-10-12 - External Link Accessibility in Static Media Components
**Learning:** Static media cards and source dialog links that point to external sites (like Medium or LinkedIn) or files (PDFs) can be overlooked if only primary call-to-action buttons are given target and screen-reader annotations.
**Action:** Ensure all external links, including card cover links and dialog references, feature target="_blank", rel="noopener noreferrer", and accessible sr-only "opens in a new tab" notices.
